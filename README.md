# Plant Disease AI Assistant

## Project Overview
Plant Disease AI Assistant is an AI-powered system designed to detect plant diseases from leaf images. It helps users identify plant diseases and provides treatment and prevention recommendations.

## Objectives
- Detect plant diseases using leaf images.
- Identify infected plants accurately.
- Provide disease information.
- Suggest treatment and prevention methods.
- Support farmers in protecting their crops.

## Key Features
- AI-based Plant Disease Detection
- Leaf Image Upload
- Disease Identification
- Treatment Recommendations
- Prevention Guidelines

## Technologies Used
- Python
- Machine Learning / Deep Learning
- HTML
- CSS
- JavaScript
- MySQL
