# Plant Disease AI Assistant

## 1. Project Overview

Plant Disease AI Assistant is an AI-powered smart agriculture system designed to detect and classify plant diseases from leaf images using Machine Learning and Deep Learning techniques.

The system helps farmers and agricultural users identify plant diseases, analyze disease severity, and receive intelligent treatment and prevention recommendations.

Our goal is to support smart farming, improve plant health monitoring, and reduce crop losses through Artificial Intelligence.

## 2. Project Objectives

- Develop an AI-based plant disease detection system.
- Identify plant diseases from leaf images.
- Support multiple plant species.
- Analyze disease severity and prediction confidence.
- Provide intelligent treatment and prevention recommendations.
- Help farmers make better agricultural decisions.
- Promote smart and sustainable agriculture.

- Model Training and Testing

- Disease Prediction

Possible Dataset:

Model performance will be evaluated using accuracy, precision, recall, and F1-score.

## 6. System Workflow

1. User registers or logs into the system.
2. User selects a plant and uploads a leaf image.
3. The system checks image quality.
4. The AI model analyzes the uploaded image.
5. The system predicts the disease and confidence score.
6. Disease severity is estimated.
7. The system provides treatment and prevention recommendations.
8. The diagnosis result is saved in the user's history.
9. User can download a diagnosis report.
